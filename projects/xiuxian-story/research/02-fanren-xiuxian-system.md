# 凡人修仙传设定体系：等级、经济、势力三层的底版

> 本文件是「道士下山」世界观三路素材之二：忘语《凡人修仙传》（2008–2013 年起点中文网连载，约 771 万字，"凡人流"开山之作 [来源](https://zh.wikipedia.org/wiki/%E5%87%A1%E4%BA%BA%E4%BF%AE%E4%BB%99%E4%BC%A0)[来源](https://zh.moegirl.org.cn/%E5%87%A1%E4%BA%BA%E4%BF%AE%E4%BB%99%E4%BC%A0)）作为"世界规则层"的底版——修为等级 + 资源经济 + 势力秩序。读完本文应能回答：这三层里哪些可以原样搬进新故事，哪些必须为"组织化修仙 + 集体大劫"重造。关键论断附来源链接（百度百科正文经 Wayback 存档核读）。

## 分节事实

### 一、修为等级：九境天梯与寿元法则

- **境界全链**：炼气（13 层，气态灵气，寿元约百余年）→ 筑基（液态灵气、辟谷御器，约 200 余岁，巅峰称"假丹"）→ 结丹（凝金丹、炼本命法宝、御空飞行，约 500 岁，巅峰称"假婴"）→ 元婴（元婴为第二生命、肉身毁可夺舍重生，人界近乎顶级战力、宗门老祖级，约千余岁）→ 化神（可调动天地灵气，因人界灵气稀薄出手折损寿元，约 2000–2500 岁）；灵界续炼虚（元婴化虚影，需周期性渡天劫）、合体（虚影与本体融合）、大乘（寿元以万年计、战力肩负一族兴衰）；渡劫不是境界而是"大乘圆满后随时引动飞升之劫的状态" [来源](https://ac.qq.com/Ask/detail/aid/zfxadylwnj)[来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)
- **主角时间线可作刻度校准**：韩立 25 岁筑基、126 岁结丹、217 岁结婴、约 885 岁化神圆满、1007 岁偷渡灵界、1468 岁炼虚后期巅峰、1925 岁合体中期、两千余岁合体后期、万余岁飞升仙界——每一大境界耗时以百年千年计，越往后断层式拉长 [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)
- **瓶颈由资源与资质双重锁死**：灵根分天灵根、真灵根、伪灵根等，韩立是四属性伪灵根（五行缺金），修炼速度先天受限，后天靠补天丹改善灵根、掌天瓶催熟灵药硬砸；炼气 11 层即遇瓶颈，需筑基丹破境 [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)[来源](https://ac.qq.com/Ask/detail/aid/zfqbdyhvyc)
- **每大境界内分初期/中期/后期（巅峰/大圆满）**，跨境界战力差距巨大但可被法宝、傀儡、虫群、阵法部分抹平——越级挑战是全书战斗叙事的基准设定 [来源](https://ac.qq.com/Ask/detail/aid/zfqbdyhvyc)
- **寿元即倒计时**：筑基 200 岁不结丹则寿元殆尽、元婴千岁不化神则坐化——修仙史的结构性焦虑来自"寿元尽头的死亡线"，而非外部敌人 [来源](https://ac.qq.com/Ask/detail/aid/zfxadylwnj)

### 二、资源经济：灵石本位与丹药硬通货

- **灵石三品货币体系**：下品/中品/上品（另有极品），百进制兑换（100 下品 = 1 中品）；灵石既是货币又是修炼资源本身。读者共识：前期以下品灵石计价、中品难得，完本时极品灵石也罕见——币值阶梯刻意维持稀缺感 [来源](https://www.pttweb.cc/bbs/CFantasy/M.1417781375.A.21D)
- **突破资源是真正的硬通货**：筑基丹有价无市——韩立凭升仙令入黄枫谷即被迫让出筑基丹换看药园的差事，后杀人夺丹、以筑基丹换上品法器；宗门以"血色禁地试炼"让低阶弟子以命相搏换取筑基丹原料，是赤裸的资源分配机制 [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)
- **坊市与多层级市场**：宗门坊市（韩立常去购置装备法阵）、万宝楼（法器专柜式商铺）、太南小会（散修定期交易会）、灵界则有黑域交易会、四族拍卖、万宝大会——市场随境界层级分化，高阶市场准入本身是身份门槛 [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)
- **产业结构环绕修士消耗**：炼丹、炼器、制符、傀儡、阵法是五大手工业；上游是灵矿（韩立被征调守卫灵矿）、灵田药园、妖兽猎杀（外星海杀妖取丹数百颗）；商业组织有乱星海"丰乐商盟"（四大商盟之一）与灵界"天东商号" [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)[来源](https://baike.baidu.com/item/%E4%B9%B1%E6%98%9F%E6%B5%B7/7774914)
- **凡人界与修仙界的资源流动**：凡人家庭送子入江湖门派谋食（三叔引韩立入七玄门）；修仙失败者（墨大夫）潜伏凡人门派图谋夺舍；凡人富商家族（嘉元城墨家）供养修士、以重金请其出手；修仙界默认不向凡人滥用武力——两界之间隔着模糊而脆弱的隔离带 [来源](https://zh.wikipedia.org/wiki/%E5%87%A1%E4%BA%BA%E4%BF%AE%E4%BB%99%E4%BC%A0)[来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)

### 三、势力图谱：正魔对立与松散秩序

- **入门即分层**：七玄门是凡人江湖门派（外门/内门弟子），修仙宗门则分杂役→记名弟子→正式弟子→管事→长老→老祖的科层；招收靠灵根检测与荐引（升仙令、师门引荐），约束靠功法传授与资源分配，传承靠师徒单传功法+本命法宝炼制之法 [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)
- **越国七大派**：掩月宗（最强）、灵兽山、黄枫谷、清虚门、化刀坞、天阙堡、巨剑门；天南修仙界大势为魔道六宗联盟与正道盟的对峙。魔道入侵越国时灵兽山（本是魔道御灵宗分支）临阵投敌，六派败逃九国盟境内重建——宗门忠诚让位于生存利益 [来源](https://m.toutiao.com/w/1872336589766793/)[来源](https://www.toutiao.com/w/1870476344247371/)
- **乱星海：海疆割据样本**：内星海由星宫统治、建超级城市天星城（内设传送阵枢纽），外星海即妖海、被强大妖兽占据；三大天灾（天风、妖兽、鬼雾）周期性肆虐；上古虚天殿每三百年开启一次、引发全海域夺宝大战——秩序由强权+灾害+秘宝周期共同塑造 [来源](https://baike.baidu.com/item/%E4%B9%B1%E6%98%9F%E6%B5%B7/7774914)
- **灵界：种族丛林与集体战争**：人族在灵界极为弱小、朝不保夕，依附天渊城等联合体自保；魔界入侵引发天渊大战、倚天城破灭级别的灭域战争；角蚩族、天云十三族、飞灵族等各自为政——高阶世界的主旋律不是个人夺宝而是种族存续 [来源](https://m.bilibili.com/opus/814825755256029321)[来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)
- **宗门对个体凉薄**：魔道入侵时黄枫谷将韩立这类弟子当弃子断后，韩立"被抛弃时乘机脱离"——旧秩序的道德破产在原著中只催生了更彻底的个人主义，未催生组织反抗（这正是新故事要改写的地方）[来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)

### 四、韩立方法论：个人主义修仙的范本

- **官方性格标签**：意志坚定、无利不起早、行事低调、能屈能伸、胆大心细、不逞英雄、心思缜密、果敢狠绝、进退有据、有情有义、尊诺守信；战斗风格"谨慎隐忍、谋定后动、手段诡谲多变" [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)
- **底牌意识**：核心外挂掌天瓶（绿液催熟灵药）从不示人，甚至用"可阻止灵气外泄的法宝残片"专门隐藏它；傀儡、噬金虫群、符宝、秘术层层备份，见面只出三分力 [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)
- **跑路是一门学问**：读者敬称"韩跑跑"——遇合体级危险"果断跑路"，打得过就打、打不过就藏，绝不殉任何阵营；另有"韩老魔"（手段狠绝）、"韩劳模"（苦修不辍）之号 [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)[来源](https://movie.douban.com/review/17010783/)
- **资源导向的行动逻辑**：看管药园、闭关炼丹、杀妖取丹、夺宝换材料——一切冒险服从资产负债表；情感与道义让位于修炼进度，"无利不起早" [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)
- **方法论本质**：在资源稀缺、秩序失灵、人人自危的世界里，一个资质平庸者的最优解是"信息不对称 + 底牌垄断 + 零组织忠诚"。原著把它推演到极致——这是要被新故事正面改造的靶子 [来源](https://baike.baidu.com/item/%E9%9F%A9%E7%AB%8B/2508547)

## 可直接用于世界观的提炼点

1. **九境天梯原样可用**（源自一、1–2 条）：炼气至渡劫九级 + 每级初/中/后期 + 寿元阶梯（百余年→200→500→千余→2000+），以及"越往后越百年千年一阶"的时间感——直接作为新世界的修为公制，主角团每升一阶都是大事件。
2. **寿元倒计时改造为动员令**（源自一、5 条 + 二、2 条）：原著寿元焦虑只驱动个人内卷（不结丹即死）；新故事里把它翻转为组织逻辑——个人突破无望时，宗门/道盟以"集体续命、传承有序"承诺换取效忠，修仙组织化的第一动力。
3. **灵石本位与丹药硬通货直接可用，分配制要重造**（源自二、1–2 条）：下/中/上品百进制、坊市、万宝楼、散修交易会照搬；但筑基丹的"以命换丹"（血色禁地模式）正适合写成旧秩序的原罪——新组织以公开配给、考核授丹取代私相授受，构成制度代差。
4. **正魔对立 + 宗门松散联盟是现成的秩序舞台**（源自三、2–3 条）：魔道六宗 vs 正道盟、临阵投敌、弃子断后——旧秩序的一切失灵瞬间（灵兽山叛变、黄枫谷弃韩立）都是新组织崛起的动员契机，照搬即用。
5. **魔界入侵 / 天渊大战直接充当"集体大劫"原型**（源自三、4 条）：原著已有"人族弱小、联合自保、灭域级战争"的框架但只作背景板；新故事把镜头从个人夺宝转到联合防线本身——大劫不再是主角渡劫的布景，而是全叙事的主战场。
6. **韩立方法论反着用**（源自四、全节）：谨慎、底牌、跑路、资源导向保留给"旧修仙者"群像（他们曾是个人主义的赢家）；新故事的主角组织正面攻克韩立式困境——底牌共享（情报库、法宝公库）、跑路改断后（掩护凡人撤离）、无利不起早改集体积累。韩立是旧世界最优解，组织化修仙是对他的系统性否定。
